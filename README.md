POO-SmartTecnoHouse

Un programa de domótica realizado para la asignatura de Programación Orientada a Objetos.

De: Sara Signes Angel

Cómo está organizado
Lo he dividido en tres partes para que el código no sea un lío:

- src/main/java/modelo/: El cerebro, aquí está el código puro que hace que todo funcione.
- src/main/java/vista/: Lo que ves en la pantalla (las ventanas, menús, textos...).
- src/main/java/controlador/: El puente, sirve para conectar los botones que tocas con el cerebro para que el programa te haga caso.

Con qué lo he hecho
- Java 17
- Swing: Para hacer las ventanas y los botones.
- JSON: Para guardar las cosas y que no se borre todo cuando cierras el programa.
